# Pricing Card Toggle

-This is a very simple JavaScript project that helps to change the price text on a webpage when a checkbox is clicked. 
-When you check the box, the price changes from monthly to yearly format automatically.

# Features
- Real-time text update using change event listener.
- Checked condition verification to toggle between two prices.
- Simple and easy to read code layout.

# Technology Used
- HTML5 for creating the layout and input fields.
- JavaScript for handling the click event and text modification.
